# 🎨 Student Portfolio

A personal portfolio website by **Chinni Krishna Popuri**.

## 📌 Overview

This project presents a student-focused portfolio showcasing skills, projects, and development work in a clean web interface.

## ✨ Highlights

- Personal introduction
- Skills and project showcase
- Responsive portfolio layout
- Simple, user-friendly presentation

## 🧰 Tech Stack

HTML • CSS • JavaScript

## 🚀 Getting Started

```bash
git clone https://github.com/krishn00000/Student-Portfolio.git
cd Student-Portfolio
```

Open the main HTML file in a browser or use a local development server.
